Self-hosted AI API Bridge

Satu key dnd-
untuk semua AI.

Sambungkan API key provider AI milikmu. DND Bridge meneruskannya lewat endpoint yang kompatibel OpenAI, mencatat pemakaian tiap key, dan bisa dijawab worker AI pribadimu.

Mulai Gratis Lihat Cara Kerja
# pakai di aplikasi AI favoritmu
Base URL : https://host-kamu/v1
API Key  : dnd-xxxxxxxxxxxxxxxx

Cara Kerja

1

Sambungkan Provider

Tempel Base URL + API key provider AI milikmu (yang kompatibel OpenAI API). Koneksi langsung divalidasi.

2

Buat Key dnd-

Satu klik, satu key dnd-... langsung jadi dan terikat ke provider pilihanmu.

3

Pakai di Mana Saja

Isi Base URL + key di aplikasi AI yang mendukung custom endpoint OpenAI, lalu pakai seperti biasa.

Fitur

Kompatibel OpenAI

Endpoint /v1 standar: chat completions, models, termasuk streaming SSE.

Dashboard Pemakaian

Tiap request dan token tercatat per key, lengkap dengan grafik 14 hari terakhir.

Worker Mode

Daftarkan akun AI pribadimu sebagai worker. Key mode worker dijawab otomatis oleh worker-mu.

Key Aman

Key asli hanya ditampilkan sekali saat dibuat. Yang disimpan hanya hash-nya. Bisa revoke kapan saja.

Rate Limit

Batas 60 request per menit per key mencegah penyalahgunaan.

Dark & Light Mode

Tampilan bersih dan modern, responsif penuh untuk HP maupun desktop.

Siap menjembatani AI-mu?

Daftar dalam hitungan detik, sambungkan providermu, dan dapatkan key pertamamu.
